# docs

| File | What it is |
|---|---|
| `Issue_Log.md` | Running record of every problem reported and resolved, and every feature built on request. Add an entry as soon as the work is finished — the format and the classification are explained at the top of the file. |
| `issue_log_images/` | Screenshots referenced by the log, named with the issue ID. Never commit screenshots containing real citizen data. |

Deployment notes and database scripts live elsewhere: `db-scripts/` for anything that touches a
database, `deployment/` for the deployment guide.
